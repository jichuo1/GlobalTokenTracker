# 发布脱敏边界

本仓库使用独立工作目录和新建 Git 历史，未复制原工程的 `.git`、开发档案、私有配置或运行数据。

保留：协调器代码、Skill、普通测试与无真实凭证的 fixture、公开模型指标快照、通用配置示例和使用文档。模型名称、官方文档 URL、协议字段、环境变量名称及本地自动定位代码属于功能数据，不是实际密钥。

排除：用户凭证、真实 provider 配置、GitHub/模型令牌、账号和项目 UUID、固定本机工程路径、数据库、用量及个人验收记录、会话/作业编号、日志、缓存和原生软件二进制。可选验收脚本从当前用户的本机配置动态获取路线，不嵌入开发者的提供商编号或 Python 安装路径。

发布前以文件清单检查和内容扫描核对工作树、暂存 blob、可达历史 blob。`scripts/privacy_check.py --compare-local` 可把本机已知凭证值只读入内存，与发布内容逐值比较，不打印或保存这些值。测试中故意使用的占位 URL 和私钥头拒绝样本有窄范围说明，不视作真实凭证。

此扫描结论限于可检查的文件和 Git 对象；不能代替对 GitHub 权限、分享设置和日后新增文件的检查。私密仓库也不应存放真实运行凭证。
